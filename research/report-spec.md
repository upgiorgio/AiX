# 自动化写作、排版设计与选题采集系统升级研究规格

- 受众：现有 Hermes / Obsidian / 微信公众号内容系统的维护与决策者
- 目的：寻找 2025-2026 年可直接用于升级的技术、数据源、评测方法和排版架构
- 范围：数据采集、选题建模、研究溯源、自动写作、质量评测、视觉排版、发布治理
- 时间：优先 2025-01 至 2026-07；基础设施型项目允许引用持续更新的官方文档
- 地域：全球技术生态，落点为中文内容与微信公众号工作流
- 输出：单文件、可离线浏览、可筛选的中文 HTML 报告
- 引用：正文内可点击来源链接；关键判断优先官方文档、官方仓库、标准与原始论文
- 必含：当前系统基线、数据源分层、选题评分公式、采集字段标准、目标架构、90 天路线图、风险与停止规则
- 排除：未经核验的产品宣传、绕过付费墙或平台权限的采集方式、把全自动发布当默认路径
- 设计方向：暖橙色的“研究编辑部控制台”，兼具杂志感与工程仪表盘的可读性

## 研究问题

1. 2025-2026 年自动化写作与 agentic research 有哪些已稳定、可接入的能力？
2. 哪些一手数据源最适合扩大中文商业、AI、社会观察与产品技术选题范围？
3. 如何从“抓文章”升级为有来源、可去重、可评分、可追踪的素材事件流？
4. 如何建立兼顾新鲜度、独特性、证据强度、受众价值与生产成本的选题结构？
5. 如何把写作质量、事实溯源、风格多样性和排版安全变成可回归测试的门禁？
6. 哪些工具值得立即接入、哪些只适合试点、哪些应明确放弃？
