# qdd.app 本地知识库（Knowledge Base）

> 原则：先整理、先审核、再改写。网站内容扩写必须以本库中**审核通过**的文档为准。

## 专家组构成与工作流

| 角色 | 职责 | 产出 |
| --- | --- | --- |
| 签证政策研究员 ×4（区域组） | 按区域调研官方来源，撰写国家知识文档初稿 | `countries/<slug>.md` |
| 事实审核员 | 独立检索交叉验证高风险事实（日期、费用、停留天数、入口域名） | `review/审核报告-2026-08-13.md` |
| 主编（人工） | 终审确认后，知识库内容才允许进入 policy-data.json 与网站 | 发布决定 |

工作流：**调研初稿 → 独立审核 → 审核报告 → 人工确认 → 改写政策数据 → 重新生成网站**

## 内容标准（继承本站方法论）

1. 来源优先级：目的地政府/移民部门 > 驻华使领馆 > 中国驻外使领馆 > 官方签证系统；旅行社与媒体只用于发现线索。
2. 三种日期分开记录：政策生效日 / 官方页面日 / 本库核验日。
3. 每个关键数字（天数、费用、期限）必须带来源名称 + URL。
4. 查不到官方原文的，标 `【待核验】`，禁止凭印象补写。
5. 不写"包过"、不写通过率、不承诺入境结果。
6. AI 可用于翻译、差异提示、结构化；关键数字必须回到官方原文核对。

## 基线资料

- 现有 20 国页面内容：`../dist/country/<slug>/index.html`（本站当前线上同版内容）
- 方法论与更新台存档：`live-snapshot/`

## 审核状态约定

每份国家文档头部标注：`初稿` → `审核通过` / `需修订`。只有「审核通过」且经人工确认的文档可进入网站改写。
