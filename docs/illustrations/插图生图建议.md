# 插图生图建议：Hermes AI 工作流

## 这篇文章的视觉原则

- 不画“泛科技感大脑”。
- 不出现 Hermes、Claude、Codex、Kimi 的真实 logo，避免品牌/商标风险。
- 核心画面必须对应文章主旨：一个人把多个 AI agent 放进同一个工作台。
- 公众号封面要能在小图里看懂：中央总控台 + 四个任务工位 + 白底暗金杂志感。
- 正文图用“解释型视觉”，分别对应多 agent 分工和公众号自动发布链路。
- 尽量不让模型生成可读文字。需要表达角色时，用抽象图标、颜色分区、线条流向，不依赖文字。

## 封面图

**English Prompt**

A premium Chinese tech magazine cover image about an AI agent workflow command center. Center composition: one elegant white-and-dark-gold control desk as the “Hermes-style” dispatcher, with four connected workstations around it representing strategy analysis, code implementation, long-context execution, and WeChat publishing. Use abstract icons only: blueprint sheet, code terminal, long timeline ribbon, magazine draft page. Warm white background, dark gold accent lines, refined serif editorial feeling, luxury but restrained, high-end product photography mixed with clean isometric interface elements. The image must clearly communicate “one central workflow orchestrates multiple AI agents”. No real brand logos, no readable text, no random letters, no human faces, no clutter, no dark cyberpunk, no generic robot brain, no orange-purple gradient blobs. Wide 2.35:1 cover composition, strong empty space for title overlay, crisp details.
