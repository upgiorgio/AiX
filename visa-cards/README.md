# 乔大帅｜中国护照出境说明书

本目录由 `generate-visa-cards.mjs` 统一生成 8 个完全自包含 HTML，共 76 张政策卡。

## 使用

1. 双击任一国家 HTML，可离线打开。
2. 点击卡片标题、结论或要点直接修改，修改自动存入浏览器。
3. 左侧切换小红书、X、方图或公众号头图尺寸。
4. 可下载单张/整套 PNG、导入导出 JSON、保存含当前修改的新 HTML。
5. “恢复官方核验版本”会恢复该 HTML 内嵌的政策快照。

## 重新生成

```bash
node generate-visa-cards.mjs
```

统一数据快照在 `policy-data.json`。更新政策时优先修改生成器中的结构化数据，再重生成全部文件。

## 日期口径

- `policyEffective`：政策生效日期。
- `officialUpdated`：本套所依据的主要官方页面日期。
- `verified`：乔大帅人工核验日期。
- 每条官方来源另带自身 `pageDate`。

> 适用：中国大陆居民、中国普通护照、短期旅游。所有签证和免签均不保证入境，最终以官方审核和口岸决定为准。
